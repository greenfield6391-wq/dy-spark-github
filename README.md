# dy-spark · 抖音续火花

在 Windows 上通过抖音网页版私信，每天定时给名单里的好友各发一句话，用来维持聊天火花（连续聊天天数）。

起因很朴素：好友二三十个，每天逐个点开太累。程序只做这一件事，跑完就退出，不常驻、不联网上传任何数据。

> **仅供学习交流。** 自动化操作可能违反平台用户协议并带来账号风险；本项目与抖音官方无关。若你把本仓库设为公开，请务必确认没有提交任何真实数据（见文末「风险与隐私」）。

---

## 先搞清楚火花规则

- 只认**一对一私聊**，群聊、点赞、评论都不算
- **双方当天各发一条**才 +1 天；你发十条对方不回，那天等于零
- 按自然日切分，跨零点算新的一天
- 断了之后有重燃机制，超过期限清零

所以程序**只能解决你这一半**。对方不回，火花一样保不住。

## 功能

| | |
|---|---|
| 操作台 | 双击即开一个本机网页控制台：今日情况 / 演练 / 立即发送 / 定时开关；黑框只是后台服务 |
| 不重复发 | 会话列表里火花图标是彩色（= 今天已续过，不管是你手动发的、别人发的还是程序发的）就跳过；灰色才发；没有火照发（帮对方开新火） |
| 找人快 | 开头扫一遍整张列表，之后按列表顺序发；发完会被顶到最前，所以用「名字 + 预估位置」直接跳，不逐屏乱翻；点人用真鼠标坐标，避免虚拟滚动重渲染点错会话 |
| 防误发 | 填字前读聊天窗头部昵称，与目标不一致就放弃并清空输入框 |
| 设置页 | 回填上次配置、已登录直接进选人页、排序（火花天数 / 今天没发的优先 / 昵称）、「今天已发」绿标、「熟」分组、话术点选（可自加可删） |
| 定时 | 网页里一键开 / 关 Windows 定时任务，改时间保存即生效；支持星期过滤、到点后随机延后 0–12 分钟（同一天重试延迟不变）；开机补跑 |
| 登录态 | 通过 CDP 连接一个常驻的有界面 Edge，登录一次即可复用；窗口被关掉会自动重连，不用重新扫码 |
| 客户版 | 单个 exe，数据统一写到 `%LOCALAPPDATA%\DySpark`，不在 exe 旁边拉文件夹；原创 Q 版小火人图标，首次运行建桌面快捷方式 |

## 快速开始

### 源码版（Windows + Python 3.9+）

```bat
git clone https://github.com/<你的用户名>/dy-spark.git
cd dy-spark
install.bat        :: 建 .venv 装依赖，只需一次
start.bat          :: 双击也行，浏览器会自动打开操作台
```

不需要额外下载浏览器，程序直接驱动系统自带的 **Microsoft Edge**。
没装 Python 的话先装 3.9+，安装时勾上 **Add python.exe to PATH**。

### exe 版

仓库里**不含 exe**（体积约 47MB，主要是 Playwright 驱动）。到 Releases 下载 `dyspark-win64-*.zip`，解压后双击即可，无需 Python。
想自己打包：用 PyInstaller 以 `app.py` 为入口，`--onefile --collect-all playwright`，并把 `config.example.yaml`、`selectors.yaml`、`assets/spark.ico` 一起打进去。

## 第一次使用

双击后浏览器打开**操作台**；第一次点「开始设置」，三步：

1. **登录**：点「打开登录窗口」，用手机抖音扫码。登录态只存在本机
2. **选好友**：程序读你的会话列表，勾谁就给谁发。群聊自动置灰；点「熟」的人走另一套话术
3. **定时间和内容**：选每天几点（建议 20:00–22:00）、间隔几秒、点选要发的句子；顺手开启定时

之后随时从操作台底部进设置页改名单。更详细的小白说明见 [`docs/使用说明.txt`](docs/使用说明.txt)。

**命令行**（调试用）：

```
app.py --run                 立即真发一轮
app.py --dry                 演练：只填字不发送
app.py --only 张三,李四      只发这几个人
app.py --status              看今天的发送记录
app.py --auto                定时任务专用（星期过滤 + 随机延迟）
app.py --menu                旧的黑框菜单
```

## 工作原理（想改代码先看这段）

- **不是爬虫也不是接口逆向**：Playwright 通过 CDP 连到本机有界面 Edge，在真实页面上点。`headless` 会撞验证码，所以固定 headed。
- **操作台不是网站**：`wizard.py` 用标准库起一个只监听 `127.0.0.1:8765` 的 `ThreadingHTTPServer`，页面是当场吐出来的 HTML 字符串，不联网下载。黑框关掉 = 后台没了 = 网页失效；定时任务走后台，不需要网页开着。
- **虚拟滚动**：会话列表一次只渲染十几项，滚轮不可靠，直接对滚动容器设 `scrollTop` 逐屏翻完并去重。
- **火花判定**：列表项图标 `gray_normal.png` = 今天没续；彩色（蓝 / 绿 / 橙 / 密友火）= 已续。这是网页版的表现，和手机客户端的灰黑色不是一回事。
- **昵称归一化**：NFKC + 去所有空白（含不间断空格 `\xa0`）+ 忽略大小写。
- **浏览器断线**：每次用之前做一次 CDP 探活，断了自动重连；同步 Playwright 不能并发，浏览器相关接口用一把锁串行，长扫描走后台不堵状态轮询。
- **抖音改版**时优先改 `selectors.yaml` 和 `core.py` 里的选择器常量；页面结构可以用 `tools/probe.py` 重新导出。

## 目录结构

```
.
├── app.py                 统一入口：操作台 / 菜单 / 定时任务
├── common.py              配置、日志、CDP 浏览器、数据目录、记录读写
├── core.py                找人、点会话、身份校验、火花判定、发送
├── wizard.py              本机网页：操作台 + 设置页（含全部前端 HTML/JS）
├── autostart.py           Windows 定时任务注册 / 查询 / 删除
├── config.example.yaml    配置模板（空名单，首次运行自动复制成 config.yaml）
├── selectors.yaml         页面元素定位规则
├── requirements.txt       playwright + PyYAML
├── start.bat / install.bat / auto_run.bat
├── docs/使用说明.txt       给最终用户的小白说明书
├── assets/                原创 Q 版小火人 ico 与预览图
└── tools/                 开发向：页面探测、导出昵称、图标生成
```

`config.yaml`、`browser-profile/`、`data/`、`logs/`、`screenshots/`、`.runtime/` 都是运行时生成的私有数据，已被 `.gitignore` 排除。

### 主要配置项

| 键 | 说明 |
|---|---|
| `friends` | 名单；`group: close` 的人用 `close_messages` 话术 |
| `send_time` | 每天几点跑 |
| `gap_seconds` | 两人之间随机停顿秒数，程序硬性上限 15 秒 |
| `skip_if_lit` | 彩火是否跳过（默认 `true`，关掉就回到旧行为） |
| `weekdays` | 只在星期几跑，`[]` = 每天 |
| `jitter_minutes` | 到点后随机延后 0–N 分钟 |
| `messages` / `close_messages` | 普通池 / 熟人池的话术 |

## 风险与隐私（请务必看）

1. **自动化操作可能违反平台用户协议**，"机器化特征行为"是平台风控重点。本项目只适合给**已经互关、本来就在聊**的好友每天发一句这种低频场景；批量加人、群发引流是另一回事。建议先用小号试跑。
2. **程序运行期间别动那个浏览器窗口**。手动滚动列表 / 点开别的会话会让「当前会话」错位；程序有昵称校验兜底，但不是 100%。跑的时候最小化即可。
3. **别调快节奏**。默认每人每天 1 条、间隔 2–15 秒。
4. 网页改版、风控弹窗、网络抖动都会让某天失败，隔几天看一眼操作台的「今日情况」。
5. **提交前检查**：`config.yaml`（真实好友名单）、`browser-profile/`（登录态）、`data/`（发送记录）、`logs/`、`screenshots/`、`probe_page.html`（真实页面快照）都不能上传。`.gitignore` 已排除，但 `git add -f` 会绕过它。
6. 所有数据只在本机：exe 版在 `%LOCALAPPDATA%\DySpark`，源码版在程序目录；程序只连 `douyin.com`，不向任何第三方服务器发送数据。
7. 想连登录态一起清掉，删掉数据目录里的 `browser-profile/` 即可。
